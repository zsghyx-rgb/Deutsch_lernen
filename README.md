# v0.37 — 拼字母提示答案 / 名词听写带冠词 / 题型可拆分 / 校内词入口

日期：2026-11-07
修改文件：`index.html`、`sw.js`（缓存版本 `dl-shell-v37`）

## 一、本版做了什么

### 1. 拼字母答错两次就显示答案

- 「拼字母」（听音拼 / 看中文拼）连续拼错 2 次后，停在当前题显示「正确答案：Sonne · 太阳」，并读一遍正确发音，约 2 秒后自动进入下一题。
- 这道题按“错”计入本次练习的正确率和盒号结算（不会因为看了答案就算对）。
- 只影响拼字母；其它题型规则不变。

### 2. 听写带定冠词

- 校内词每天的听写：如果是名词，读的时候读「die Sonne」，孩子要连定冠词一起写。
- 对答案时的手写叠影、正确答案、保存给家长批改的记录都统一成「die Sonne」；动词照旧只写单词（laufen）。
- 普通练习里的听写（听音写 / 看中文写）同样改为带冠词，提示改成“名词连定冠词一起写”。
- 描红仍然只描单词本身，不受影响。

### 3. 单词练习拆开，题型单独勾选

设置 → 儿童模式 → 学习方式下面新增「单词练习的题型」：

- 描红
- 听音选词
- 拼字母（听音拼 + 看中文拼）
- 听写（听音写 + 看中文写）
- 挖空
- 冠词

只勾选的题型会出现在练习里；一个都没勾时会提示并自动保留一项。校内词每天的练习也按这里的勾选来安排（例如只勾“描红 + 拼字母”，第 4 天就不会出现默写）。

### 4. 本周校内词的入口和《校内词》本子的含义

- 除了设置里的录入框，**生词本 → 校内词** 本子页面里现在也有「本周校内词」的录入框，填完直接保存。
- 《校内词》是一个长期保留的单词本：所有填过的校内词都会留在这里，周结束后继续进入常规复习，也可以在生词本里查看。
- 每周的“本周词表”只是这一周要练、要听写的名单；每周在录入框里换一次，不会清空《校内词》里已有的词。
- 从《校内词》里删掉某个词，之后的练习和听写就不会再出现它。

## 二、测试记录（本地浏览器）

- 设置里只勾“拼字母”后开始校内词：第 1 天不再描红，直接进入拼字母，说明题型过滤生效。
- 拼字母连续拼错两次：显示「正确答案：Sonne · 太阳」，2 秒后自动进入下一个词。
- 校内词听写：记录里保存为「die Sonne」，孩子自评/家长批改显示的也是完整答案。
- 普通练习只勾“听写”时：显示「正确答案：der Tisch」，冠词包含在答案和叠影里。
- 题型全部取消时：提示“至少保留一种题型”，并保留当前项。
- 生词本 → 校内词页面：显示本周词表（die Sonne / laufen）和说明，保存后周 id 不变、词表正确。
- 控制台无 JS 报错（仅有 favicon 的 404）。

## 三、已知限制

- 题型勾选只存在当前设备，不参与同步；在手机上改题型不会自动改变平板上的设置。
- 旧版保存的听写记录（v0.36 及以前）里名词没有冠词，家长批改历史条目时会看到不带冠词的写法。

## 四、下一版（v0.38）候选

- 题型设置参与同步，家长在手机上改完平板立即生效。
- 拼字母连错时的答案也可以点“再试一次”而不是直接跳过。
- 校内词支持从班级群直接粘贴整行（逗号/顿号分隔）自动拆分。

## 五、部署

把本文件夹里的 `index.html`、`sw.js` 覆盖到站点根目录即可。`sw.js` 缓存版本已升到 `dl-shell-v37`，首次打开会自动更新。
