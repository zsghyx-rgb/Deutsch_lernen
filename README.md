# 德语 A2 学习本（PWA）

纯静态网页，无后端。API Key、Apps Script 网址、同步口令**只存在你自己设备的浏览器里**，不在代码里，也不会上传。

## 一、部署到 GitHub Pages
1. 在 GitHub 新建仓库（如 `deutsch`），把本文件夹里的文件上传到仓库根目录（`Code.gs` 可不传）。
2. 仓库 Settings → Pages → Source 选 `main` 分支、`/ (root)` → Save。
3. 约 1 分钟后访问 `https://<你的用户名>.github.io/<仓库名>/`。

## 二、配置 Google Drive 同步（Apps Script）
1. 打开 https://script.google.com → 新建项目，把 `Code.gs` 内容粘贴进去，保存。
2. 左侧「项目设置」→「脚本属性」→ 添加属性：名称 `TOKEN`，值填一串自己编的长口令（如 20 位随机字符）。
3. 右上角「部署」→「新建部署」→ 类型选「Web 应用」：
   - 执行身份：**我**
   - 有权访问的用户：**任何人**
   部署并按提示授权（需要访问 Drive）。复制得到的 `…/exec` 网址。
4. 数据会保存在你 Drive 根目录的 `deutsch-lernen-data.json`。
5. 以后修改脚本后，需要「管理部署」→ 编辑 → 新版本，网址才会生效。

## 三、在应用里填写
打开网页 → 底部「设置」：
- **Claude API Key**：在 console.anthropic.com 创建（建议单独建一个 Key，并设置用量上限）。
- **模型**：默认 `claude-haiku-5-5`（便宜快速），可改。
- **Apps Script 网址** 和 **同步口令**（与 TOKEN 相同）。
点「测试 AI」「立即同步」确认可用。每台设备都要各填一次。

## 四、安装到手机
- iPhone：Safari 打开 → 分享 → 添加到主屏幕。
- Android：Chrome 打开 → 菜单 → 安装应用。

## 同步规则
打开应用、切回应用、每次学习操作后 3 秒会自动同步。两台设备都有改动时自动**合并**（掌握状态取并集，生词按单词合并，导入主题按 ID 合并），不会互相覆盖。设置页可导出/导入 JSON 备份。

## 隐私与风险提示
- API Key 存在浏览器 localStorage，别在公用设备上使用；泄露后到控制台删除该 Key 即可。
- 同步网址 + 口令一起泄露，别人才能读写你的学习数据；口令请足够长。
- 仓库公开也没关系：里面没有任何密钥。
- 学习数据里的句子会发给 Anthropic API 用于翻译和查词，不含其他个人信息。

## 更新说明（v2）
- **其他 AI**：设置里选「OpenAI 兼容接口」，可用预设（OpenAI / DeepSeek / 通义千问 / Gemini）或自填 Base URL、Key、模型名。个别服务可能不允许浏览器直连（跨域），「测试 AI」会提示；模型名以服务商文档为准。
- **不用 AI 也能查词**：未配置 Key 时，点词自动用免费的 MyMemory 机器翻译显示中文意思（无原形/词性/变形，质量一般，匿名额度有限）；导入文本也可用它逐句翻译。
- **查词典**：点词面板里有 德语助手、Langenscheidt、有道、Linguee、Wiktionary 链接，也可在设置里填自己的词典网址模板（`{w}` 代表单词）。
- **主题管理**：主页可排序（自定义/名称/进度/最新）；点「编辑」后可 ↑↓ 调整顺序、删除主题（内置主题可在设置里恢复）；导入/AI 主题里可删除单句。删除会同步到云端，不会被另一台设备“复活”。
- **外观**：设置里可选 跟随系统（默认）/ 浅色 / 深色。
- **iPhone**：已禁用双击放大和双指缩放。

## 更新说明（v3）
- **同名主题自动合并**：AI 生成、导入、中译德保存时，若主题名（不分大小写和多余空格）已存在，会把新句子追加进去，重复句子自动跳过。AI 生成预览里的“主题名称”默认是你输入的场景，可修改，输入框会提示已有主题。内置主题不能追加句子，同名时会另建一个“我的”主题。
- **中译德**：底部新增“翻译”页。输入中文（可多行），用 AI（未配置则用免费 MyMemory）翻译成德语；译文可手动修改、点 ▶ 听发音，再选已有主题或新建主题保存。
- **解释来源标注**：点词面板、生词本里会标出来源，如“AI 翻译（模型名）”或“MyMemory 机器翻译”。
